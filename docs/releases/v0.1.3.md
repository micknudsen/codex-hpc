# codex-hpc v0.1.3

Fixes Codex shell startup on Apptainer clusters where Bubblewrap cannot bind
the container root. The compute launcher selects a workspace permission
profile with scoped reads, uses Apptainer underlay for nested directory binds,
and provides `/dev/full` for Bubblewrap's device setup.

The updated client includes its matching remote helper. Run `codex-hpc setup`
after upgrading. The release reuses the existing signed v0.1.2 SIF. Compute
nodes must support Apptainer's `--underlay` option, which Apptainer 1.5.5
supports with a deprecation warning.

On the affected Slurm cluster, Codex's shell tool printed the workspace
directory and read back a workspace marker after reconnecting. Reads of
sentinel files in a sibling directory, the host home, and the persistent
state root all failed. Both sessions used the published v0.1.2 SIF.
